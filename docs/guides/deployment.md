# Deployment Guide

Panduan ini mencakup dua jalur deployment:
- **[Opsi A](#opsi-a--manual-tanpa-coolify)** — Manual menggunakan Docker Compose langsung di server (tanpa panel manajemen).
- **[Opsi B](#opsi-b--dengan-coolify)** — Menggunakan [Coolify](https://coolify.io) sebagai platform deployment self-hosted.

Untuk konfigurasi Cloudflare (CDN/WAF/Tunnel), lihat [cloudflare-setup.md](./cloudflare-setup.md).

---

## Prasyarat

### Spesifikasi Server
| Komponen | Minimum | Rekomendasi |
|---|---|---|
| CPU | 4 vCPU | 8 vCPU |
| RAM | 8 GB | 16 GB |
| Storage | 80 GB SSD | 160 GB SSD NVMe |
| OS | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

> **Provider yang direkomendasikan:** Hetzner (CX42 — €22/bulan) atau DigitalOcean (8 vCPU / 16 GB).

### Software di Server
- Docker Engine 24+ dan Docker Compose v2 (diinstall otomatis oleh `setup.sh` jika belum ada)
- Git

### Yang Perlu Disiapkan Sebelum Deploy
- [ ] Akses SSH ke server
- [ ] Domain atau subdomain yang sudah diarahkan ke IP server (opsional, bisa pakai IP langsung untuk internal)
- [ ] Kredensial SMTP untuk email notifikasi (opsional)
- [ ] Gemini API Key untuk fitur AI (opsional)

## Opsi A — Manual (Tanpa Coolify)

Cocok untuk: deployment langsung ke VPS atau server fisik tanpa panel manajemen.

### Langkah 1 — Clone Repository

```bash
git clone <repo-url> cfd
cd cfd
```

### Langkah 2 — Jalankan Setup Pertama Kali

```bash
bash deploy/setup.sh
```

Script ini akan otomatis:
1. Menginstall Docker Engine jika belum ada
2. Membuat file `.env` dari `.env.example` dengan secret yang di-generate secara aman (`JWT_SECRET`, `BACKUP_ENCRYPTION_KEY`, `POSTGRES_PASSWORD`)
3. Menampilkan prompt untuk mengisi nilai wajib di `.env`
4. Melakukan build Docker image dan menjalankan container

### Langkah 3 — Isi Nilai Wajib di `.env`

Saat script berhenti dan meminta input, buka file `.env` di editor dan isi:

```bash
nano .env
```

Nilai yang **wajib** diubah:

```dotenv
# URL aplikasi yang akan diakses user (gunakan domain atau IP server)
APP_URL=https://cfd.example.com

# SMTP untuk notifikasi email cicilan bank loan
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=noreply@example.com
SMTP_PASSWORD=your-app-password
SMTP_FROM=noreply@example.com
```

Nilai yang sudah di-generate otomatis — **jangan diubah**:
```dotenv
FRS_JWT_SECRET=<auto-generated>
BACKUP_ENCRYPTION_KEY=<auto-generated>
POSTGRES_PASSWORD=<auto-generated>
```

Setelah selesai, tekan **Enter** di terminal untuk melanjutkan setup.

### Langkah 4 — Verifikasi

Setelah setup selesai, verifikasi container berjalan:

```bash
docker compose ps
```

Output yang diharapkan:
```
NAME        STATUS          PORTS
cfd-db      running         5432/tcp
cfd-app     running         0.0.0.0:5000->5000/tcp
```

Akses aplikasi di: `http://<IP_SERVER>:5000`

### Langkah 5 — Deploy Update

Untuk setiap update kode setelahnya, cukup jalankan:

```bash
bash deploy/deploy.sh
```

Script ini melakukan: `git pull` → `docker compose up -d --build`.

---

### Perintah Operasional Harian

```bash
# Lihat status container
docker compose ps

# Lihat log realtime
docker compose logs -f app
docker compose logs -f db

# Restart aplikasi tanpa rebuild
docker compose restart app

# Stop semua container
docker compose down

# Stop dan hapus volume (HATI-HATI: menghapus data DB)
docker compose down -v
```

## Opsi B — Dengan Coolify

Coolify adalah platform deployment self-hosted yang menyediakan UI untuk mengelola container, environment variable, SSL otomatis, dan deployment via Git.

### Langkah 1 — Install Coolify di Server

SSH ke server, lalu jalankan installer resmi Coolify:

```bash
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

Tunggu hingga selesai (~2–5 menit). Coolify berjalan di port `8000` secara default.

Akses Coolify UI di: `http://<IP_SERVER>:8000`

> **Penting:** Amankan akses port 8000 di firewall — jangan expose ke publik kecuali sudah pasang HTTPS. Lihat bagian [Keamanan Coolify](#keamanan-coolify-panel).

### Langkah 2 — Registrasi Akun Coolify

1. Buka `http://<IP_SERVER>:8000`
2. Klik **Register** — akun pertama otomatis menjadi admin
3. Isi email dan password
4. Klik **Register**

### Langkah 3 — Tambahkan Server

Coolify bisa deploy ke server yang sama (localhost) atau server remote.

**Untuk deploy ke server yang sama:**
1. Di sidebar, klik **Servers**
2. Klik tombol **+ Add** → pilih **Localhost**
3. Klik **Continue** → Coolify akan validate koneksi ke localhost
4. Pastikan status **Reachable** berwarna hijau

### Langkah 4 — Buat Project

1. Di sidebar, klik **Projects**
2. Klik **+ New Project**
3. Isi nama: `Corporate Finance Dashboard`
4. Klik **Create**

### Langkah 5 — Tambahkan Resource: PostgreSQL

Database harus dibuat lebih dahulu sebelum aplikasi.

1. Di dalam project, klik **+ New Resource**
2. Pilih **Database** → **PostgreSQL**
3. Pilih server: `localhost`
4. Konfigurasi:
   - **Name:** `cfd-db`
   - **PostgreSQL Version:** `16`
   - **Database Name:** `cfd_db`
   - **Username:** `cfd_user`
   - **Password:** generate atau isi manual (catat, akan dibutuhkan di langkah berikutnya)
5. Klik **Save**, lalu klik **Start**
6. Tunggu status berubah menjadi **Running**
7. Catat **Internal URL** PostgreSQL yang ditampilkan Coolify — formatnya:
   ```
   postgresql://cfd_user:<password>@<hostname>:5432/cfd_db
   ```

### Langkah 6 — Tambahkan Resource: Aplikasi

1. Di dalam project yang sama, klik **+ New Resource**
2. Pilih **Application**
3. Pilih **Git Repository (Public)** atau **Private Repository** sesuai setup
4. Isi URL repository: `https://github.com/<org>/cfd`
5. **Branch:** `main`
6. **Build Pack:** pilih **Dockerfile** (Coolify akan otomatis detect `Dockerfile` di root)
7. Pilih server: `localhost`
8. Klik **Continue**

### Langkah 7 — Konfigurasi Environment Variables

Di halaman aplikasi, masuk ke tab **Environment Variables** dan isi semua nilai:

```dotenv
NODE_ENV=production
PORT=5000
APP_URL=https://cfd.example.com

# Gunakan Internal URL dari PostgreSQL Coolify (langkah 5)
DATABASE_URL=postgresql://cfd_user:<password>@<hostname>:5432/cfd_db

# Generate dengan: openssl rand -hex 64
FRS_JWT_SECRET=<strong-random-secret>
FRS_JWT_EXPIRES_IN=30m
FRS_KEEP_ALIVE_INTERVAL_MS=15000

# Generate dengan: openssl rand -hex 32
BACKUP_ENCRYPTION_KEY=<64-char-hex>
BACKUP_LOCATION=./backups

# SMTP (opsional)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=noreply@example.com
SMTP_PASSWORD=your-app-password
SMTP_FROM=noreply@example.com

# AI (opsional)
GEMINI_API_KEY=

# Rate limiting
RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX=500
RATE_LIMIT_AUTH_MAX=10
RATE_LIMIT_AUTH_IP_MAX=200
```

> **Catatan:** Di Coolify, `DATABASE_URL` di-set manual ke URL internal PostgreSQL — berbeda dengan Opsi A yang di-override otomatis oleh `docker-compose.yml`.

### Langkah 8 — Konfigurasi Domain & Port

1. Di tab **General** aplikasi:
   - **Ports Exposes:** `5000`
2. Di tab **Domains:**
   - Klik **+ Add Domain**
   - Isi: `cfd.example.com` (domain yang sudah diarahkan ke server)
   - Aktifkan **Generate SSL Certificate** (Let's Encrypt — gratis)
3. Klik **Save**

### Langkah 9 — Deploy

1. Klik tombol **Deploy** di pojok kanan atas
2. Coolify akan:
   - Clone repository
   - Build Docker image menggunakan `Dockerfile`
   - Jalankan migrasi database (via `docker-entrypoint.sh`)
   - Start container
3. Monitor progress di tab **Logs** (Build Logs)
4. Setelah status **Running**, akses aplikasi di domain yang dikonfigurasi

### Langkah 10 — Setup Auto-Deploy (Opsional)

Agar setiap `git push ke `main` langsung trigger deploy otomatis:

1. Di tab **General** aplikasi, aktifkan **Auto Deploy**
2. Di tab **Webhooks**, copy URL webhook yang disediakan Coolify
3. Di GitHub/GitLab repository settings:
   - Buka **Settings → Webhooks → Add webhook**
   - Paste URL webhook Coolify
   - Content type: `application/json`
   - Events: **Just the push event**
4. Klik **Add webhook**

Setelah ini, setiap push ke `main` akan otomatis trigger rebuild dan deploy.

### Keamanan Coolify Panel

Port `8000` (Coolify UI) sebaiknya tidak diakses langsung dari internet.

**Opsi 1 — Akses via SSH Tunnel (paling aman):**
```bash
# Di mesin lokal (laptop)
ssh -L 8000:localhost:8000 user@<IP_SERVER>
# Lalu buka http://localhost:8000 di browser
```

**Opsi 2 — Pasang domain + SSL untuk Coolify:**
Di Coolify Settings → Update Coolify URL ke `https://coolify.example.com` dan aktifkan SSL.

**Opsi 3 — Firewall rule:**
Izinkan akses port 8000 hanya dari IP kantor/VPN:
```bash
ufw allow from <IP_KANTOR> to any port 8000
ufw deny 8000
```

## Checklist Post-Deployment

Setelah deploy berhasil, verifikasi hal-hal berikut:

- [ ] Aplikasi bisa diakses di URL yang dikonfigurasi
- [ ] Login berhasil dengan kredensial admin
- [ ] Data dari database tampil di dashboard
- [ ] Upload file (realisasi/Excel) berhasil disimpan
- [ ] Notifikasi email terkirim (jika SMTP dikonfigurasi)
- [ ] HTTPS aktif (SSL certificate valid)
- [ ] Log tidak menampilkan error kritis: `docker compose logs app`

## Troubleshooting

### Container `cfd-app` gagal start

```bash
docker compose logs app
```

Penyebab umum:
- `DATABASE_URL` salah → cek koneksi ke PostgreSQL
- `FRS_JWT_SECRET` kosong → wajib diisi di `.env`
- Port 5000 sudah dipakai proses lain → `lsof -i :5000`

### Migrasi database gagal

```bash
# Jalankan migrasi manual
docker compose exec app npx tsx scripts/migrate.ts
```

### Database tidak bisa diakses

```bash
# Cek status PostgreSQL
docker compose exec db pg_isready -U cfd_user -d cfd_db

# Lihat log DB
docker compose logs db
```

### Reset total (development only — menghapus semua data)

```bash
docker compose down -v   # Hapus container + volume
docker compose up -d --build
```
