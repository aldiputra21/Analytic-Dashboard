# Panduan Pengguna (User Manual)
## Corporate Finance Dashboard (CFD)

Selamat datang di Panduan Pengguna **Corporate Finance Dashboard (CFD)** untuk PT Titian Servis Indonesia. Dokumentasi ini telah dipecah menjadi beberapa bagian untuk mempermudah pencarian informasi.

### Daftar Isi

1.  **[RBAC & Autentikasi](./rbac-auth.md)**
    - Peran Pengguna (Role), Login, Logout, Lupa Password, Aktivasi Akun, Profil Pengguna.
2.  **[Analitik & Dashboard](./analytics.md)**
    - Ringkasan KPI, Filter Dashboard, Benchmarking, Analisis Tren.
3.  **[Persetujuan & Notifikasi](./approvals-notifications.md)**
    - Alur Persetujuan (Maker & Approver), Monitoring, Notifikasi Real-time.
4.  **[Laporan Keuangan](./financial-statements.md)**
    - Manajemen Neraca, Laba Rugi, Proyeksi Laba Rugi, Bulk Upload (Excel).
5.  **[Arus Kas & Pinjaman](./cash-flow.md)**
    - Arus Kas Mingguan, Realisasi, Proyeksi Arus Kas, Pinjaman Bank.
6.  **[Pengelolaan Perusahaan](./corporate-management.md)**
    - Master Data Perusahaan, Departemen, Cost Center, Proyek.
7.  **[Laporan Manajerial](./reports.md)**
    - Laporan Laba Rugi Proyek (per Cost Center).
8.  **[Pengelolaan Bisnis](./business-management.md)**
    - Sektor Bisnis, Mata Uang, Master Bank.
9.  **[Pengelolaan Pengguna](./user-management.md)**
    - Manajemen User, Role, dan Permission.
10. **[Pengelolaan & Monitoring Sistem](./system-monitoring.md)**
    - Ambang Batas (Threshold), Konfigurasi Approval, Audit Log.
11. **[Pesan Kesalahan & Masalah Umum](./troubleshooting.md)**
    - Kode Error, Masalah UI, Kontak IT Support.
