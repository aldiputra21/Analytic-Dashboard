# Pesan Kesalahan & Masalah Umum

Panduan ini membantu Anda mengenali dan menangani kendala teknis yang mungkin terjadi saat menggunakan aplikasi.

## 1. Pesan Kesalahan Umum

| Kode/Pesan | Arti | Solusi |
|---|---|---|
| **401 Unauthorized** | Sesi Anda telah berakhir. | Silakan login kembali. |
| **403 Forbidden** | Anda tidak memiliki hak akses untuk menu ini. | Hubungi admin untuk memeriksa Role & Permission Anda. |
| **400 Bad Request** | Input tidak valid (misal: format tanggal salah). | Periksa kembali isian formulir Anda. |
| **500 Server Error** | Terjadi masalah pada server. | Tunggu beberapa saat dan coba lagi. Jika berlanjut, hubungi IT Support. |
| **Rate Limit Exceeded** | Terlalu banyak permintaan dalam waktu singkat. | Tunggu beberapa detik sebelum melakukan aksi berikutnya. |

## 2. Masalah UI & Navigasi

### 2.1 Data Tidak Muncul
- **Penyebab**: Filter sedang aktif atau memang tidak ada data untuk periode tersebut.
- **Solusi**: Klik tombol **Clear Filter** atau ganti periode pencarian.

### 2.2 Gagal Upload Excel
- **Penyebab**: Struktur template diubah atau ada kolom wajib yang kosong.
- **Solusi**: Unduh template terbaru, salin data tanpa mengubah header, dan pastikan kolom mandatory (bertanda *) sudah terisi.

### 2.3 Notifikasi Tidak Masuk
- **Penyebab**: Koneksi internet tidak stabil.
- **Solusi**: Periksa status koneksi Anda di pojok kanan bawah. Jika muncul pesan "Offline", refresh halaman saat koneksi sudah kembali stabil.
