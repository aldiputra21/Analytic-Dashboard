# Specs: Cash Flow Enhancements

## Goals
Improve accessibility and consistency of the Cash Flow management module.

## Features
1. **Search Filter**: Ability to filter cash flow entries by project name or description via a text input.
2. **UI Consistency**: Standardize fonts in the datatable for financial figures.
3. **Improved Form Flow**:
    - Project association toggle ("Terkait Proyek?") instead of entity type selection.
    - Compressed layout for Investing and Financing fields (2 columns per row).

## Acceptance Criteria
- Search input is visible and functional in the Cash Flow filter bar.
- Cash In, Cash Out, and Net Flow columns use the same font as the rest of the table.
- Toggle switch correctly toggles project selection visibility in the form.
- Investing and Financing sections match the 2-column layout of the Operating section.
